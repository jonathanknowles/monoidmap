Description

Provides internal support for the monoidmap package.

This module defines the NonNull type of values that are not null, and functions for constructing maps of NonNull values from ordinary maps.

fromMap :: MonoidNull v => Map k v -> Map k (NonNull v) Source #

Constructs a map of non-null values from an ordinary Map, removing all null values.

This function selects which of the fromMap_* implementations below is used by the public fromMap function of the monoidmap package.

fromMapWith :: MonoidNull v2 => (v1 -> v2) -> Map k v1 -> Map k (NonNull v2) Source #

Constructs a map of non-null values from an ordinary Map, applying the given function to all values, and removing all null values.

This function selects which of the fromMapWith_* implementations below is used by the public fromMapWith function of the monoidmap package.
